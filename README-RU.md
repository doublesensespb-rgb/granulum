# GRAIN FORM — справочник владельца

Всё, что нужно, чтобы собирать, менять и выпускать плагин самому или с любым помощником (ИИ или программист).
Версия на момент написания: **0.99.6** (видна в плагине на табличке рядом с названием).

## 2. Как собрать новую версию

### Вариант А — в облаке GitHub (ничего ставить не надо)
1. Открой https://github.com/doublesensespb-rgb/granulum/actions/workflows/build.yml
2. Справа кнопка **Run workflow** → ветка `main` → в поле **What to build** выбери `all` (или только `windows` / `mac`) → **Run workflow**.
3. Через ~15 минут готовые `GRAIN-FORM-Windows.zip` и `GRAIN-FORM-macOS.zip` появятся тут:
   https://github.com/doublesensespb-rgb/granulum/tree/builds
4. Переименуй под версию, например `GRAIN-FORM-0.97-Windows.zip`.
5. Если Mac-сборка «отменилась» (cancelled) — это занятые серверы GitHub, не ошибка. Запусти ещё раз с `mac` (в поле Mac runner оставь `macos-15`).

Репозиторий приватный: GitHub даёт бесплатные минуты сборки каждый месяц (Windows и Mac считаются дороже Linux). Одна сборка GRAIN FORM — примерно час «облачных» минут, этого хватает на ~30 сборок в месяц на бесплатном аккаунте.
Тарифы: https://docs.github.com/en/billing/managing-billing-for-your-products/managing-billing-for-github-actions/about-billing-for-github-actions

### Вариант Б — на своём Windows-компьютере (работает без интернета)
Один раз установить (пока интернет есть):
- Visual Studio 2022 Community — https://visualstudio.microsoft.com/vs/community/ — при установке отметить **«Desktop development with C++»** («Разработка классических приложений на C++»).
- CMake — https://cmake.org/download/ — при установке отметить **«Add CMake to the system PATH»**.
- Git — https://git-scm.com/download/win (нужен только чтобы забирать/отправлять код на GitHub).

Потом каждый раз: распаковать офлайн-архив (или папку с кодом), положить папку `JUCE` рядом с `CMakeLists.txt`
(в офлайн-архиве она уже на месте) и дважды кликнуть `tools\build-windows.bat`.
Готовый плагин появится в папке `out`.

Mac-версию можно собрать только на Mac (Xcode) или через вариант А.

## 3. Как менять плагин без меня

### С другим ИИ-агентом
Подойдёт любой агент, который умеет работать с кодом и GitHub: Claude Code (https://claude.com/claude-code),
OpenAI Codex, Cursor, Kimi и т.п. Первое сообщение агенту:

> Это мой VST-плагин GRAIN FORM: https://github.com/doublesensespb-rgb/granulum
> Сначала полностью прочитай AGENTS.md и следуй правилам оттуда.
> Я не программист: делай всё сам, сначала согласуй со мной правки текстом, покажи картинку дизайна до сборки
> и не запускай сборку без моей команды. Отвечай по-русски.
> Задача: <что хочешь изменить>

### С программистом
Это обычный проект на **C++17 + JUCE 8 + CMake**. Ищи «JUCE developer» — например на форуме JUCE
(https://forum.juce.com), KVR (https://www.kvraudio.com/forum/), Upwork, Kwork/FL.ru. Дай ему ссылку на репозиторий
и попроси прочитать `AGENTS.md`.

### Три вещи, которые нельзя менять (иначе сломаются проекты пользователей)
1. Коды плагина в `CMakeLists.txt`: `PLUGIN_MANUFACTURER_CODE Thmt`, `PLUGIN_CODE GrFm`, `BUNDLE_ID`, `PRODUCT_NAME`.
2. Названия параметров (`ParamID` в `Source/PluginProcessor.h`). Удалить функцию можно, параметр — нет.
3. Формат пресетов (`.gpreset`) — только добавлять новое, не переименовывать старое.

Обязательно скажи это любому помощнику (в `AGENTS.md` это уже написано).

### Как называть версии
0.96 → 0.97 → … → 1.0 (первый релиз). Номер ставится в `CMakeLists.txt`: строка `project(Granulum VERSION 0.9.6)`
(0.99 = `0.9.9`, 1.0 = `1.0.0`). Табличка с версией в плагине обновится сама.
Промежуточные версии вроде 0.99.2: строка `set(GRAINFORM_LABEL "0.99.2")` там же (это только надпись; для DAW номер остаётся 0.9.9).
После КАЖДОЙ сборки помощник обязан сам прислать ссылки и новый офлайн-архив этой версии.

### Что в плагине сейчас (0.99.6)
**Новое в 0.99.6:**
- OSC 1: переключатель ADDITIVE | WAVE (MIX как режим убран). В ADDITIVE справа вверху на экране палочек — ползунок MIX WAVE (по умолчанию 0%,
  двойной клик — сброс в 0): подмешивает полную волну к палочкам. Волна (∿⩘⊓∿) выбирается кнопками в режиме WAVE; кнопки видны только в WAVE.
  Волна в MIX WAVE читается теми же зёрнами, что и палочки (одно облако зёрен, а не два — вдвое легче для процессора).
- CLIP — чистый клипер как Soft Clipper во FL: звук не меняет, просто не даёт выйти за 0 dB (×4 передискретизация). Кнопка горит медью, когда включена.
- OUTPUT до +24 dB (можно сделать синт очень громким; с CLIP упрётся в 0 dB).
- RANDOM ▾: отдельные галочки Filter 1, Filter 2, LFO 1, LFO 2, LFO 3 (форма, Sync, размер). Стрелка по центру кнопки.
- Шумы: убраны BROWN, AC HUM, BUZZ, TRANSFORMER, AIR, LEAVES. Остались WHITE, PINK, BLUE, TAPE HISS, VINYL, PAPER, DUST, FROST,
  METAL RAIN, RAIN, FIRE, BUBBLES. PINK на 5 полутонов выше. Старые пресеты получают ближайший шум
  (BROWN→PINK, HUM/BUZZ/TRANSFORMER→TAPE HISS, AIR→WHITE, LEAVES→RAIN).
- PITCH шума: −12…+24 полутона.
- Экран GRAIN FIELD показывает зёрна всех источников: OSC 1, SAMPLE (с белым контуром), NOISE (мелкие и тусклые).
- Без «грязи»: VOWEL выровнен по громкости, резонанс фильтров компенсируется, аккорды тише на каждую ноту.
- Против треска при быстрой игре: бюджет зёрен (больше 200 одновременно — облака немного редеют, громкость та же), быстрое чтение волны.

**Всё остальное (как в 0.99.5):**
- Дизайн GRAPHITE: графит, медный акцент, шрифт Inter. LFO — стальной синий, шалфей, слоновая кость. Табличка версии у названия.
- Порядок: OSC 1 ADDITIVE (палочки), OSC 2 SUB, OSC 3 SAMPLE, OSC 4 NOISE. Цифры у фильтров/эффектов «1 2 3 4» в том же порядке.
- OSC 1: 16 палочек, аккорды, форма волны (синус/пила/квадрат/треугольник), ряд переключателей GRAIN (медный = в зёрна,
  серый = чисто; можно протянуть мышкой), тихая подсказка при первом запуске.
- OSC 2 SUB: 5 палочек (тон, октава, октава+квинта, 2 октавы, 2 октавы+терция) с формой волны, VOL, OCT (−3…+1), SEMI. Без грануляра;
  в фильтры/эффекты — только если горит цифра 2.
- OSC 3 SAMPLE (меню SOUNDS, свой WAV, крестик — удалить), OSC 4 NOISE (PITCH). PAN у OSC 1, 3, 4.
- TUNE у OSC 1 и OSC 3 SAMPLE: плавный питч −48…+48 полутонов без ступенек (как COARSE в Serum), на него можно кидать LFO.
- PITCH рядом с OUTPUT: общий питч всего синта ±2 октавы, плавно.
- OSC 2, 3, 4 сворачиваются в полоску (стрелка справа): видно номер, тип, звук и ручку VOL. OSC 1 всегда открыт.
- Номера гармоник 1…16 под палочками OSC 1 (тусклые, под мышью ярче).
- Пресеты: клик по имени — окно со списком (папки слева, клик = послушать, двойной клик = загрузить и закрыть).
- Окно SAVE внутри плагина — папки слева (+ FOLDER, правый клик: переименовать/удалить пустую), пресеты папки справа,
  REPLACE если имя уже есть. В меню пресетов папки открываются подменю, стрелки листают все пресеты подряд.
  Папки — обычные папки в Документы/GRAIN FORM/Presets.
- OSC 1 WAVE — полная волна (SINE/SAW/SQUARE/TRIANGLE) со всеми гармониками без алиасинга. Грануляр работает во всех режимах.
- Шумы OSC 4: все на 3 полутона выше базового (список — в «Новое в 0.99.6»).
- Палочка с LFO (OSC 1 и SUB) двигается вместе с LFO.
- Дисторшн общий (как в Serum): все осцилляторы с горящей цифрой DIST искажаются вместе — шум трещит на синусе. Типы FOLD, TUBE, HARD CLIP, SQUARE; ручки DRIVE и MIX (TONE и BITCRUSH убраны). Передискретизация ×4 и выравнивание громкости. Подогнан по записи из Serum (лучше всего с шумом BLUE/WHITE).
- INIT включает MONO.
- RANDOM ALL ▾ — галочками выбрать, что рандомить (палочки, зёрна, Filter 1, Filter 2, дисторшн, дилей, реверб, LFO 1–3).
- INIT и пресет без аудиофайла очищают файл OSC 3.
- Без кликов на старте ноты: минимальная атака 4 мс (S-кривая), повтор ноты плавно сменяет старую, громкость от LFO меняется не быстрее ~3 мс.
- SPREAD сам расширяет зёрна (работает и при SCATTER 0).
- LFO в режимах RETRIG и ENV запускаются заново на каждой новой ноте, в том числе при легато в MONO.
- Смена пресета (и INIT) мягко глушит старый звук: ноты, зёрна, хвосты дилея и реверба не наслаиваются на новый пресет.
- LFO на палочки (OSC 1 и SUB): кинуть вкладку LFO на палочку, один LFO на палочку, глубина — колесом мыши, правый клик — убрать.
- Глубина LFO в процентах (как в Serum): наведи на кружок LFO у ручки — рядом с ним появится число (например −45%), значение ручки остаётся видно;
  у палочек — над линией LFO.
  Колесо мыши — шаг 5%, с Shift — 1%; тянуть мышью — шаг 1%.
- Грануляр: BLOOM, SMEAR, SCATTER, SHIMMER, DRIFT, CHIME + SIZE, SPEED, POSITION, DENSITY, SPREAD, MIX; RANDOM с характерами.
- Луп: OFF / LOOP / PING-PONG / ONE-SHOT, флажки на экране.
- Фильтры: LP12, LP24, HP, BP, PEAK (GAIN ±36 дБ, Q), COMB, VOWEL + окошко фильтра. Дисторшн (общий для всех осцилляторов, как в Serum): FOLD, TUBE, HARD CLIP, SQUARE (делает волну квадратной), ручки DRIVE и MIX. Дилей, реверб.
- 3 LFO со своими точками (до 16), INTO GRAINS (без щелчков), одна ручка RATE (как в Serum); ADSR; UNDO.
- Ручки как в Serum (Shift/Ctrl — точнее), OUTPUT −36…+24 dB, кнопка CLIP включает/выключает чистый клипер (нажимается вся рамка, включённая горит медью). Курсор без «руки».

## 5. Если что-то пошло не так

- **FL показывает старую версию** — удалить старый `GRAIN FORM.vst3` из `C:\Program Files\Common Files\VST3`,
  положить новый, в FL: Options → Manage plugins → Find more plugins (или Rescan).
- **Сборка на GitHub упала** — Actions → открыть красный запуск → прочитать ошибку → передать текст ИИ-агенту или программисту.
- **Пропал доступ к GitHub** — всё есть в офлайн-архиве: создай новый репозиторий и загрузи туда папку с кодом
  (в ней уже есть вся история: папка `.git`), поправь адрес в справочнике.
